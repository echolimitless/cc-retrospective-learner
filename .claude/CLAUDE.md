# cc-retrospective-learner

Claude Code のセッションデータを活用した、ふりかえりベースの学習機構。
セットアップスクリプトで `~/.claude/` に必要なファイルを配置し、セッション中のふりかえりを通じて feedback や行動パターンを蓄積する。

## プロジェクト構造

- `templates/` — `~/.claude/` にコピーされるテンプレートファイル群
- `cc-retrospective-learner-setup.sh` — セットアップ/ロールバックスクリプト
- `CHANGELOG.md` — 変更履歴（Why・意思決定の背景を含む）

テンプレートの変更は必ず `templates/` 内で行う。`~/.claude/` の本番ファイルを直接編集しない。

## ふりかえり方式

セットアップ時に選択する2つの方式がある。

- **毎回方式**: セッション開始時にふりかえりを確認・実行
- **オンデマンド方式**: セッション開始時は何もしない。ユーザーが手動で実行

両方式とも `session-reviewer` / `weekly-promoter` サブエージェントを共有し、`reviewed_sessions.md` で済み判定を行う。詳細は `templates/cc-retrospective-learner-design.md` を参照。

## 変更時のルール

### CHANGELOG.md の更新

このプロジェクトに変更を加えた場合、`CHANGELOG.md` にエントリを追記すること。

構成:
- **Pain**: 変更の動機・課題
- **調査・検証で分かったこと**: 技術的な発見・検証結果
- **検討した選択肢**: 比較検討した案と判断理由
- **意思決定**: 各判断とその根拠
- **設計原則・思想**: 設計上の考え方
- **変更内容**: 新規作成・変更・削除ファイル一覧

ブログ執筆やAIに読ませることを想定し、Whyや意思決定の背景を重視すること。

### やってはいけないこと

- `~/.claude/` の本番ファイルを直接変更する（必ず `templates/` を変更し、再セットアップで反映する）
- セットアップスクリプトのロールバック処理を壊す変更（ロールバックで削除するファイルリストの更新忘れに注意）
